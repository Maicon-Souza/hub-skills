Como instalar

No Claude (web ou app), funciona também no plano gratuito:

  1. Baixe o .zip da skill (não precisa descompactar).
  2. No Claude, abra Configurações (Settings) → Capacidades (Capabilities) e ative Execução de código e criação de arquivos (Code execution and file creation, ou Create and edit files). Isso só precisa ser feito uma vez.
  3. Vá em Personalizar (Customize) → Skills.
  4. Clique em + → Criar skill (Create skill) → Enviar uma skill (Upload a skill) e escolha o .zip.
  5. Ative a skill e peça algo relacionado a ela no chat.

Se a opção de skills não aparecer ou estiver cinza, confira o passo 2. Em contas de empresa (Team ou Enterprise), o administrador precisa ter liberado as skills.

No Claude Code: descompacte e copie a pasta para ~/.claude/skills/.
